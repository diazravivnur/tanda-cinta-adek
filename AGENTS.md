# Proyek: PWA kontraksi & tendangan bayi
Spesifikasi lengkap ada di SPEC.md. Baca hanya bagian yang relevan dengan tugas.
- Stack: React + Vite + TypeScript, Firebase (Auth Google, Firestore, FCM, Functions).
- UI Bahasa Indonesia, kontras tinggi, target pengguna iPhone (PWA standalone).
- Logika pola kontraksi harus pure function + unit test (Vitest).
- Semua ambang 5-1-1 hanya di src/config/thresholds.ts.
- Jangan commit .env atau kredensial; jangan tulis email/nomor telepon di kode.
- Kerjakan satu milestone per sesi; jelaskan rencana sebelum mengubah banyak file.
